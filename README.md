# Biblioteca da Ellen

 Sobre o projeto:

Este projeto é um sistema simples de biblioteca feito em Python.

O programa permite cadastrar livros, emprestar e devolver livros, listar os livros cadastrados, buscar livros pelo título ou autor e ordenar os livros por título, autor ou ano.

Os livros são armazenados em um arquivo CSV.

## Funcionalidades

O sistema possui as seguintes opções:

1. Cadastrar livro: permite cadastrar um novo livro informando título, autor, código e ano.
2. Emprestar livro: permite emprestar um livro pelo código e altera seu status para "emprestado".
3. Devolver livro: permite devolver um livro e altera seu status para "disponível".
4. Listar livros: mostra os livros cadastrados, seus autores, códigos, anos e status.
5. Buscar livro: permite procurar um livro pelo título ou pelo autor.
6. Ordenar livros: permite organizar os livros por título, autor ou ano.
7. Sair: encerra o programa.

## Como usar

Para executar o programa, abra o arquivo `main.py` no VS Code e execute o programa.

Depois, escolha uma das opções apresentadas no menu e siga as instruções que aparecem no terminal.

## Arquivos do projeto

* `main.py` — contém o código principal do programa e suas funções.
* `livros.csv` — armazena os dados dos livros cadastrados.
* `README.md` — apresenta informações sobre o projeto.

## Tecnologias utilizadas

* Python
* CSV
* Visual Studio Code

## Objetivo

O objetivo do projeto é desenvolver um sistema simples de gerenciamento de uma biblioteca, praticando conceitos de programação em Python, como funções, condicionais, estruturas de repetição, listas, dicionários e manipulação de arquivos CSV.
